# 4gps 实施计划

依据：docs/4gps修改依据.md。基础提交：0a5841118adf6e362a490ddceaa6ce67f41fe545。用户授权修改并推送公开仓库的 4gps 分支。

## 全局约束
中文注释；基础 MATLAB R2025a；保留用户未提交的格式整理；不改 main；不连续展开 4 GS/s 长记录；A/B 共享核心；不得把 20 MHz 当作主采样率。

## 任务 1：采样体系、主链与回归
实现独立 ADC/RFDC/PL/基带参数、两种 profile、雷达参数族、8 SPC 接口和状态 FIR/D8，并接入 A/B 主链；按秒派生捕获点数和容量；区分物理时间、可用时间、命令时间、实际发射时间；实现短窗 4 GS/s ADC/RFDC 专项模型；补充修改意见列出的全部回归并更新旧测试。最终接口与验证映射见 docs/4gps修改报告.md。

## 任务 2：排版和文档
统一 LF、UTF-8、四空格缩进；删除无意义空行，保留逻辑段落；长表达式合理续行；更新 README 和修改映射报告。

## 任务 3：验收、审查、上传
运行全部 MATLAB 测试、Code Analyzer、正式 A/B 示例和专项 ADC 示例；记录实际结果；审查整体差异和敏感数据；提交并推送 origin/4gps；核对远端 SHA。
