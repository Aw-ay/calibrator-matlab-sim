# OTA、阵列与宽带增量说明

本次保留 500 MS/s → 8 SPC → FIR/D8 → 62.5 MS/s、500 MHz GSC、A/B 共核、公共 H/V 量程选择和独立校准测量边界。
代码注释使用中文；MATLAB 源文件按 UTF-8、LF、四空格和 120 列整理。

## 已提供远场及其边界

- 文件：`uav_pattern/farfield_resolution1deg.txt`；181 个 theta × 360 个 phi，共 65,160 点。
- 用户确认：2.8 GHz、UAV 天线 H/V 同时激励。两路相对幅相、Horizontal/Vertical 基和相位参考原点仍待确认。
- H/V 分量按 `10^(dBi/20) * exp(j*phase)` 转成复电场，按复数插值，phi 周期接缝连续；不直接平均相位角。
- 总增益峰值 6.641 dBi；打印后的总增益与两分量功率和最大相差约 0.009776 dB，保留原数值而不强制归一。
- SHA-256：`f6ce3b27953f868b9ff1336fb8e43ff969d90b2680b36b661c0c9342f5ca3b79`。

一份文件给出一个已施加激励的二分量复场 F，不是完整 2×2 Jones。两个独立激励文件配合可逆激励矩阵 A 才能由 J=F/A 恢复端口矩阵。
解析模式允许基未知；空间投影要求显式基定义。`run_ota_demo` 显式采用未确认的 Ludwig-3 假设并固定为单一有效联合模式。
内部第一通道只是该模式的计算坐标，第二通道关闭，不对应“测得了 H 列”或“V 列为零”。其接收模式也依赖互易归一化假设，不能替代真实合路器/端口测量。

## 主链参考面、姿态与阵列

RP1 表示仪器端口复波，RP2_OTA 表示统一 ENU 横向实基中的复场。主链前向为雷达阵列 Tx → 传播 → UAV Rx；反向为 UAV Tx → 传播 → 雷达阵列 Rx/DBF。
天线使用真实复场幅相，不额外重复乘增益。接收互易使用非共轭转置；共轭转置会错误消除传播前后的天线相位。

姿态采用列向量主动 ZYX：R_ENU_FROM_BODY = Rz(yaw) Ry(pitch) Rx(roll)。安装旋转通过矩阵相乘，BODY 杆臂与 ANT 相位中心分别旋转；角速率贡献杆臂速度。
真实姿态只进入传播，导航观测独立外推后进入补偿。核心配置中删除物理方向图、阵列误差、平台模型及宽带 plant 参数。
日志新增真实/观测相位中心和两组四元数；延迟账本记录首末块实际相位中心往返时延。

`cfg.target.reference_plane='RP2_OTA'` 时目标算子为 inv(Jtx_est) S inv(Jrx_est)；名义 Jones 缺列、出域或逆增益过大时拒绝。
物理方向图位于 `cfg.antenna.pattern`，独立的名义模型位于 `cfg.antenna.calibration_pattern`。默认均为理想模型，不自动把物理误差喂给补偿器。

阵列具有阵元坐标、独立 Tx/Rx 误差、嵌入式 AEP、归一权重、扫描、逐阵元接收信号和 DBF。
默认 1×1 可退化到原主链；4×4 均匀阵列每个激励极化的 Tx 总功率固定，波束方向单程电压增益为 4，双程为 16。
EIRP 按声明的每激励极化功率计算；缺系统噪声温度时 G/T 保持 NaN，不补造结果。被动机体回波也经过阵列收发响应。

## 宽带、时延和门控

已捕获完整波形支持 LINEAR、LAGRANGE、FARROW、WINDOWED_SINC 分数插值；默认 LINEAR 保留历史兼容。
随机读取不增加固定延迟；独立流式高阶实现显式增加 4 个样点以避免未来数据读取。
比较脚本覆盖 1/2/5/10/20 MHz 的幅度、相位、群延迟、ZDR 和 PhiDP 误差，报告扣除了声明的固定延迟。
传播路径仍采用原线性分数延迟；高阶选项接入 DRFM 捕获回放，不代表所有物理传播插值已经升级。

频率校准通过独立训练和留出频点的 X/Y 激励测量估计 H(f)，然后拟合带正则化和增益限制的因果逆 FIR。
主链可选物理 RX 频响位于 500 MS/s 公共前端后、三量程分叉前；TX 频响位于静态 RF 网络后、62.5 MS/s 栅格上。
完整捕获后 RX 校准冲洗并裁去声明的固定延迟；共享 TX 校准因果执行，调度提前相应延迟，bank 占用、冲突检查覆盖前驱和尾巴。
目标对齐标签 `t_tx_aligned_s` 与数字校准后非零输出 `t_tx_first_nonzero_s` 分开，宽带 `t_tx_actual_s` 由门控后非零DAC基带样点确认。
主链另给出 `t_tx_first_nonzero_rf_s`，由 DAC 量化和物理 TX 网络后的实际仿真波形检出；它仍不是实物仪表检波阈值。
安全和半双工门同时覆盖数字 FIR 与物理 TX 网络的历史；关断时清空历史，防止复开泄露旧波形。
物理 TX 尾长须不超过独立声明的 `tx_rf_tail_bound_samples`；核心据此扩展窗口和资源占用，不读取真实 FIR 抽头。
RX/TX 校准域按估计入射 Doppler 与回放频移后的各自频带检查，超出已测频点覆盖时拒绝。
当前宽带主链限定 DRFM 模式，其他源模式显式拒绝。校准温度、功率和量程域必须声明且不外推；示例只覆盖声明的合成工作点，并非真实扫温/扫功率测量。

`run_wideband_system_demo` 使用同一实际合成 H(f) 生成测量和物理网络，在正式采样链比较校准波形与无频响误差参考；两条链都启用相同高阶回放。
此误差还包括 ADC/DAC 量化、有限捕获和固定抗混叠滤波的影响，不等于独立频域拟合残差。

## 不确定度与验收

不确定度工具以明确测量方程、26 个标准不确定度及完整协方差传播到功率、时延、频率、ZDR、PhiDP 和 RCS，并用固定随机种子的蒙特卡洛交叉检查。
它允许相关 H/V 公共项抵消，输出源表、输入/输出协方差和 Jacobian。所有数值源均是合成假设；k=2 的扩展不确定度不构成校准证书。

本次没有提供独立双端口激励远场、真实 VNA 测量/协方差、实测阵元 AEP、RTL、板卡或完整连续光行时模型。
运动仍为短块冻结近似，环境/EMC 也不是实测耦合全模型。因此软件测试通过不代表原四十项规格全部验收通过。
自动测试数量、逐项状态和原规格覆盖边界以 `results/acceptance` 为准。
