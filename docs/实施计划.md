# 双偏振标定仪 MATLAB 实施计划

依据：`../../calibrator_matlab_design/01_审查与两阶段总体设计.md`、函数清单及 T01–T40 验证矩阵。

目标：交付可在 MATLAB R2025a 运行的复包络参考工程，A/B 共享仪器核心，中文注释、中文报告。原始设计资料保持不变。

技术：基础 MATLAB、matlab.unittest；不依赖专用信号处理工具箱。复杂硬件逐拍、实测计量资格及未确认扩展不冒充已验证。

## 工作分解

- [x] 几何、方向图与传播：实现 WGS84/ENU、姿态、Jones、单径/镜像和流式多径；测试坐标、Friis、极化、跨块延迟。
- [x] 转换器与数字前端：实现量化、公共噪声、三档、NCO、FIR 抽取、时间契约；测试边界、旋向和跨块状态。
- [x] 共享核心与闭环：配置、波形、因果检测、整脉冲选档、bank 引用、DRFM/DDS/LIVE/MUTE、独立 DMA、校准估计、雷达观测；先写闭环及故障测试，运行失败后实现。
- [x] 机载适配与交付：带延迟的导航、运动、姿态、温度/供电/EMC/被动散射；A/B 退化测试、演示图、运行报告及实现覆盖表。
- [x] MATLAB 实机运行自动测试、代码检查和 A/B 演示，审查结果并修正。

## 接口约定

包采用 `+rtsim/+职责`，物理波形为 N×2 复数功率波（sqrt_W）。配置演示采样率 20 MHz、载频 2.8 GHz、脉宽 10 us、PRI 1 ms、物理距离 2 km、虚拟距离 20 km。算法演示支持 ENVELOPE；未实现的高保真档明确拒绝。

网格包括 gsc0(uint64)、fraction0_ticks、step_num、step_den、count、fs_Hz、f_gsc_Hz、epoch_id、clock_id；gsc0 大整数求差后转换，局部样点用 index0。

分工目录互不重叠；共享核心仅接收观测及估计，不接受传播真值。校准用独立激励的测量拟合，不直接求真实链逆矩阵。未取得实测数据的验收项为 BLOCKED_MISSING_DATA，未完成原规格全部子场景为 NOT_RUN，并单独列出已经通过的自动测试。
